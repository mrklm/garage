🚦 Navigation principale

Garage est organisé en cinq grandes pages :

- Général
- Pleins
- Entretiens
- Graphiques
- Paramètres

La page Paramètres regroupe les réglages et les informations qui ne sont
pas utilisées au quotidien :

- Paramètres > Véhicules
- Paramètres > Entretien
- Paramètres > Préconisations
- Paramètres > Apparence
- Paramètres > Données
- Paramètres > Aide

---

🚦 Premier démarrage (Général)

Lors du premier lancement, il est normal que le message suivant apparaisse :

> Aucun véhicule

La base est vide, et tout est prêt pour commencer 🙂

👉 Ajoutez simplement votre premier véhicule dans Paramètres > Véhicules.

---

🏠 Général

La page Général affiche une carte pour chaque véhicule.

Chaque carte peut présenter :

- la consommation moyenne
- l'état de la batterie, si une tension a été saisie
- le coût estimé des entretiens à prévoir
- les informations principales du véhicule
- le dernier kilométrage connu
- les rappels d'entretien

Le dernier kilométrage n'est pas saisi dans la fiche véhicule.
Il est déterminé automatiquement à partir des pleins et des entretiens
enregistrés.

Chaque carte propose aussi deux actions rapides :

- + Plein
- + Entretien

Ces boutons sélectionnent automatiquement le véhicule de la carte et
ouvrent le formulaire correspondant.

---

🚘 Paramètres > Véhicules

Cette section permet de gérer les véhicules.

Vous pouvez :

- ajouter un véhicule
- modifier ses informations
- supprimer un véhicule
- ajouter ou remplacer sa photo

Les informations disponibles sont :

- nom
- marque
- modèle
- motorisation
- énergie
- année
- immatriculation

Pour ajouter une photo, cliquez sur Ajouter ou Modifier, puis choisissez
une image avec Parcourir.

Les formats PNG, JPG, JPEG et BMP sont acceptés.
Garage conserve ensuite une version adaptée pour l'application.

Quand un véhicule est enregistré, il devient le véhicule actif.

⚠️ La suppression d'un véhicule est définitive.
Les données associées au véhicule sont supprimées avec lui.

---

⛽ Pleins

La page Pleins permet d'enregistrer les pleins de carburant du véhicule
actif.

Pour chaque plein, vous pouvez saisir :

- la date
- le kilométrage
- les litres
- le prix/L
- le total
- le lieu

Si vous laissez le total vide, Garage le calcule automatiquement avec :

litres × prix/L

Vous pouvez aussi modifier ou supprimer un plein déjà enregistré.

Ces données alimentent notamment :

- le dernier kilométrage connu
- la consommation moyenne
- les graphiques de consommation et de prix du carburant

---

🔩 Entretiens

La page Entretiens contient l'historique et la saisie des opérations
réalisées sur le véhicule actif.

Chaque entretien peut inclure :

- une date
- un kilométrage
- une nature d'intervention
- un type d'entretien
- un coût
- la personne ou le garage qui l'a réalisé
- une tension batterie
- un détail

La nature d'intervention permet de distinguer :

- Réparation
- Entretien
- Entretien & Réparation

Vous pouvez ajouter, modifier ou supprimer un entretien.

Les types d'entretien proposés dans le formulaire sont configurés dans
Paramètres > Entretien.

---

🚨 Paramètres > Entretien

Cette section permet de configurer les types d'entretien pour le véhicule
actif.

Pour chaque type, vous pouvez définir :

- un nom
- une fréquence en kilomètres
- une fréquence en mois
- l'activation ou non du rappel

Un type peut utiliser une fréquence kilométrique, une fréquence temporelle,
ou les deux.

Les rappels activés sont affichés sur les cartes de la page Général.

Garage utilise l'historique enregistré pour déterminer si un rappel est :

✅ à jour

❌ en retard

🟠 bientôt à prévoir

La pré-alerte orange apparaît lorsque l'échéance approche.
Le texte du rappel indique dans combien de temps ou dans combien de
kilomètres l'entretien est à prévoir.

---

📋 Paramètres > Préconisations

Cette section permet d'enregistrer les préconisations ou informations
constructeur associées à un véhicule.

Exemples :

- type d'huile moteur
- pression des pneumatiques
- dimensions de pneus
- notes constructeur utiles

Ces préconisations sont des notes libres.
Elles ne remplacent pas les types d'entretien configurés dans
Paramètres > Entretien.

---

📊 Graphiques

La page Graphiques permet de visualiser les données du véhicule actif.

Les graphiques disponibles sont :

- consommation en L/100 km
- prix du litre dans le temps
- coûts des entretiens et réparations

Vous pouvez afficher les trois graphes ensemble ou choisir un graphe
individuel.

Un filtre permet aussi de masquer les consommations anormalement hautes
dans le graphe de consommation.

---

🔐 Données & confidentialité

Garage fonctionne entièrement en local :

- aucune connexion internet requise
- aucune donnée envoyée à un serveur
- aucun compte utilisateur
- open source et gratuit, vous pouvez distribuer ce programme autour de vous

Vos données restent sur votre ordinateur.

---

💾 Paramètres > Données

Cette section permet de gérer les sauvegardes.

Exporter une sauvegarde crée une archive contenant :

- les données Garage
- les photos des véhicules

Importer une sauvegarde remplace les données et les photos actuelles par
celles contenues dans la sauvegarde sélectionnée.

Avant l'importation, Garage crée automatiquement une sauvegarde de sécurité
des données actuelles.

Après une importation réussie, Garage vous demande de redémarrer
l'application pour utiliser les données restaurées.

💡 Une sauvegarde régulière vous garantit tranquillité et sécurité.

---

👓️ Paramètres > Apparence

Cette section permet de choisir le thème de l'application.

Plusieurs thèmes sont proposés :

- 🕶️ Des thèmes sombres
- 👓️ Des thèmes clairs
- 🤡 Des thèmes rigolos

Le changement de thème est appliqué immédiatement.

---

❓ Paramètres > Aide

Cette aide est disponible directement dans Paramètres > Aide.

Vous pouvez la consulter à tout moment depuis l'application.

---

❓ Questions fréquentes ❓
 
🚘 Le message « Aucun véhicule » s'affiche

C'est normal lors du premier lancement.

Ouvrez Paramètres > Véhicules, puis cliquez sur Ajouter pour commencer.

---

⛽ Le total d'un plein est-il obligatoire ?

Non.

Si vous indiquez les litres et le prix/L, vous pouvez laisser le total vide.
Garage le calculera automatiquement.

---

🔧 Pourquoi aucun type d'entretien n'est proposé ?

Les types d'entretien sont configurés par véhicule.

Ouvrez Paramètres > Entretien pour créer les types nécessaires avant de
saisir un entretien.

---

🍎 macOS bloque l'application au lancement

- ⚙️ Cliquez sur Préférences Système
- 🔑 Confirmez l'autorisation d'ouvrir Garage

- ⛽ un historique des pleins

- 🚨 des rappels pour anticiper les opérations à prévoir
- 📊 des graphiques pour suivre l'évolution dans le temps
